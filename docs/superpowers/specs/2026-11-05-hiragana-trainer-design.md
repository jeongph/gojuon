# 히라가나 암기 웹앱 설계

작성일: 2026-11-05

## 의도

일본어를 처음 공부하는 한국어 사용자가 웹 브라우저에서 바로 히라가나를 외울 수 있는 가벼운 도구. 로그인, 저장, 추적이 없고 새로고침하면 초기화되어도 된다.

## 시장조사 요약

- **대표 서비스**: Tofugu(연상법 가이드 + 퀴즈), RealKana(열 단위 선택 + 로마자 입력), Kana Pro(진도 기반 자동 출제), KanaDojo(고르기·입력·역방향·속도 모드, 테마·폰트 다수), Duolingo·Renshuu(종합 앱 안의 가나 코스), Dr. Moku·Japan Foundation Memory Hint(그림 연상법), Nazori(획순 쓰기 판정).
- **공통 패턴**: 행(또는 열) 단위로 범위 선택 → 인식(4지선다) → 회상(타이핑) 순으로 난이도 상승 → 틀린 글자 반복 출제. 연상법(mnemonic)은 모양과 소리를 잇는 이야기로 제시.
- **Tofugu 교수 원칙**: 쓰기보다 읽기 우선, 행 하나를 배우면 앞선 행까지 누적 복습, 답을 보기 전에 떠올리기, 마지막에 시간 재기.
- **한국 시장**: 앱스토어 위주(일본문자, 히라가나 닌자 등). 한국어 UI의 웹 서비스는 드물고, 한국어 발음 표기(아·카·사)를 함께 보여 주는 것이 입문자에게 유리.
- **빈자리**: 계정·구독 없이, 한국어로, 조용한 디자인의 웹 도구.

## 목표 / 비목표

- 목표: 46자 + 탁음·반탁음 + 요음을 표·카드·퀴즈로 익힌다. 모바일과 데스크톱 모두 편하다. 키보드만으로 퀴즈를 풀 수 있다.
- 비목표: 계정, 진도 저장, 가타카나(후속), 획순 애니메이션(후속), 단어·문법 학습.
- 실패 조건: 화려하거나 템플릿 같은 디자인, 영어 UI, 눈이 피로한 고대비 색.

## 화면

1. **표**: 세트 탭(기본 46자 / 탁음·반탁음 / 요음) + 행×단 그리드 + 상세 패널(큰 글자, 로마자, 한국어 발음, 듣기, 모양 힌트, 발음 메모, 예시 단어). 데스크톱은 우측 고정 패널, 모바일은 바텀 시트.
2. **학습**: 범위 선택 → 카드 뒤집기. 앞면(가나/발음)과 순서(표 순서/섞기) 선택. "다시 볼게요"는 큐 끝으로 보낸다. 한 바퀴 끝나면 다시 본 글자만 복습 가능.
3. **퀴즈**: 범위, 방식(가나→소리 / 소리→가나 / 로마자 입력), 문제 수 선택. 오답 선택지는 같은 행·단에서 우선 추출하고 로마자가 같은 글자(じ/ぢ)는 제외. 정답은 자동 진행, 오답은 정답을 보여 주고 사용자가 넘김. 결과에서 틀린 글자만 다시 풀기.

## 데이터 모델

`Kana { id, script, group, row, col, kana, romaji, alt[], korean, hint?, note?, example? }`. 행 단위 `KanaRow`로 묶어 표와 범위 선택에 재사용. 로마자는 헵번식을 대표로 두고 훈령식(si, ti, tu, hu)과 입력 편의 표기(nn, wo/o)를 `alt`로 인정.
